# Forkify Project

A recipe application that allows users to:
- search for recipes from an external API
- view ingredients and cooking time
- bookmark favorite recipes
- upload and manage custom recipes

Final project of an advanced JavaScript course (MVC architecture, API, Web Storage).

Live Demo  
https://forkify-steriba.netlify.app/

## Technologies Used
- JavaScript ES6+
- Parcel bundler
- Fetch API / AJAX calls
- MVC architecture
- Local Storage for bookmarks
